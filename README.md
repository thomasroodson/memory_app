# DevMemory — Memory Game

A browser-based memory game built with React and TypeScript. The player reveals cards, finds matching pairs, and tries to finish the board with as few moves as possible.

I built this project to practice component-based UI development, state management, reusable components, and small game interactions.

## Features

- Card grid with matching pairs
- Move counter and elapsed-time display
- Restart game action
- Separate components for cards, buttons, and game information
- Typed data models for the grid items

## Tech stack

- React
- TypeScript
- Create React App
- styled-components

## Run locally

```bash
npm install
npm start
```

The development server opens at [http://localhost:3000](http://localhost:3000).

## Project structure

- `src/components` — reusable UI components
- `src/data` — card data
- `src/helpers` — game-related helper functions
- `src/types` — TypeScript types

---

This project was created as a front-end learning exercise focused on interactive UI and React state.
